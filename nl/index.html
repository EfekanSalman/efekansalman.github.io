CASE 01 // TRANSFORMER–BREINUITLIJNING LLM × Neurowetenschap

AxonLM: neuroanatomie peilen in een taalmodel

Probleem
Kunnen transformerrepresentaties neuroanatomische connectiviteit vastleggen?
Mijn bijdrage
Ik bouwde de modulaire PyTorch GPT-2-onderzoeksbasis en FFN-probescripts.
Methode
Lineaire probes op feed-forward-activaties, vergeleken met connectiviteit uit de Allen Brain Atlas.
Resultaat
De repository rapporteert AUC 0,963 voor neuroanatomische decodering.

CASE 02 // COGNITIEVE ARCHITECTUUR Agentsimulatie

NeuroConscious: uitbreidbare testomgeving voor agents

Probleem
Hoe beïnvloeden interne behoeften en stemming beslissingen van een agent in een virtuele wereld?
Mijn bijdrage
Ik ontwierp de modulaire agentarchitectuur en de onderdelen voor interne toestand, stemming en motivatie.

Objectgeoriënteerde Python-modules koppelen de interne toestand aan actiekeuze en omgevingsinteractie.

Een open-source testomgeving voor autonoom, biologisch geïnspireerd gedrag.

CASE 03 // SYNAPTISCHE PLASTICITEIT Neuromorfe simulatie

STDP-SNN: leren op basis van spikes verkennen

Probleem
Hoe veranderen spiketiming en laterale competitie synaptische gewichten?
Mijn bijdrage
Ik bouwde een spiking-netwerksimulator met een interactieve verkenningsinterface.
Methode
Leaky integrate-and-fire-neuronen, STDP-leren en winner-take-all-remming.
Resultaat
Een simulator voor spikeactiviteit en plasticiteit; hier is geen benchmarkscore gepubliceerd.
ARCHITECTUUROVERZICHT
Invoerstroom→LIF-spikes→STDP-update
Code en methoden op GitHub↗ Probeer het interactieve lab↓
