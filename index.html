CASE 01 // TRANSFORMER–BRAIN ALIGNMENT LLM × Neuroscience

AxonLM: probing neuroanatomy in a language model

Problem
Can transformer representations encode neuroanatomical connectivity?
My contribution
Built the modular PyTorch GPT-2 research codebase and FFN probing scripts.
Method
Linear probes on feed-forward activations, compared with Allen Brain Atlas connectivity.
Result
The repository reports AUC 0.963 for neuroanatomical decoding.

CASE 03 // SYNAPTIC PLASTICITY Neuromorphic simulation

STDP-SNN: exploring spike-driven learning

Problem
How do spike timing and lateral competition change synaptic weights?
My contribution
Built a spiking-network simulator with an interactive exploration interface.
Method
Leaky integrate-and-fire neurons, STDP learning, and winner-take-all inhibition.
Result
A simulator for observing spike activity and plasticity; no benchmark score is published here.
ARCHITECTURE SNAPSHOT
Input current→LIF spikes→STDP update
